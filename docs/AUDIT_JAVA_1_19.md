# Аудит проекта относительно цели Java Edition 1.19

Дата аудита: 2026-11-20. Проверены README, точка входа, parity checklist, спецификация, загрузчик моделей, система звуков и Node test runner на ветке main.

## Важное расхождение цели

Текущая документация проекта противоречива:
- README описывает активную совместимость с Java 1.12.2.
- docs/PARITY.md указывает Java 1.20.x как reference target.
- docs/SPEC.md содержит функции и ресурсные ожидания из более поздних версий.
- src/render/entity_models.js принимает manifest только с minecraftVersion = 1.20.1.

До реализации новых систем требуется единый контракт: эта работа использует Java Edition 1.19 как конечную версию. Нельзя считать наличие 1.20.1-моделей доказательством совместимости с 1.19.

## Что обнаружено в коде

| Область | Состояние по исходникам |
|---|---|
| Игровой цикл | Фиксированный тик 20 TPS и отдельный рендер описаны в src/main.js |
| Блоки/предметы | Реестры и базовые игровые операции существуют; README заявляет около 80 блоков |
| Мир | Seeded generation, несколько биомов, пещеры и руды; не полный генератор 1.19 |
| Игрок | Базовая физика, выживание/творческий режим, инвентарь и добыча |
| Контейнеры | Сундуки и печи; README отмечает непостоянное хранение содержимого контейнеров |
| Мобы | Частичный AI, спавн и боевые взаимодействия; не полный набор и не полная ванильная симуляция |
| Мультиплеер | Экспериментальная синхронизация; не авторитетная общая симуляция выживания |
| Звук | src/game/sounds.js синтезирует короткие оригинальные звуки через Web Audio; это не оригинальные звуковые файлы игры |
| Анимации/модели | Загрузчик читает локальный набор JSON-моделей/анимаций, но требует manifest версии 1.20.1; fallback встроен |
| Тесты | Node runner импортирует набор регрессионных suite; этот аудит не запускает браузерный визуальный QA |

## Критические пробелы для Java 1.19

- Полная версия-специфичная база блоков, предметов, blockstates и рецептов.
- Точные биомы и multi-noise параметры, структуры и лут.
- Nether/End механики и генерация, соответствующие 1.19.
- Вода и лава с обновлением потоков; погода и полный свет между чанками.
- Полный набор мобов 1.19, AI goals, естественный спавн и mob caps.
- Villagers, raids, breeding, taming и торговля с точными правилами.
- Редстоун, поршни, quasi-connectivity, компараторы и автоматизация.
- Зачарования, зелья, эффекты, полный бой и урон.
- Команды, NBT, datapacks и ресурс-паки с форматом 1.19.
- Звуковая система с таблицей sound events и лицензированными ресурсами.
- Версионная система анимаций и entity rigs, проверенная именно на целевой версии.

## Проверки, которые обязательны для каждой следующей реализации

1. Unit/regression tests на формулы и граничные условия.
2. Golden tests для генерации по фиксированным seed и координатам.
3. Save/load round-trip и migration tests.
4. Проверки chunk borders и unload/reload.
5. Тесты multiplayer consistency там, где механика общая.
6. Запуск полного Node test runner и browser tests при доступном браузере.
7. Проверка отсутствия ошибок консоли и ручной QA отдельно от автоматических тестов.

## Принцип релиза

Ни одна функция не помечается «полностью готово», пока нет теста или точного источника и описанных ограничений. Документация не подменяет реализацию. Неполные функции должны быть явно помечены.
