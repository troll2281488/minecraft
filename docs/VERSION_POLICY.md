# Active version policy

- Active compatibility target: **Minecraft Java Edition 1.19.x**.
- Historical coverage may document Classic through 1.18, but must be tagged with the exact version range.
- Java Edition only. Bedrock behavior is out of scope unless explicitly labelled as a comparison.
- No 1.20+ content belongs in the 1.19 catalog.
- The old 1.12.2 compatibility pass is historical context, not the active target.
- A feature is not considered 1.19-compatible merely because its ID exists. Its state schema, recipe, loot, generation, tick behavior, interactions and save migration must be checked.
- Never mark a parity item exact without a regression test or a primary technical source.
- Asset provenance and license notices remain attached to the assets they cover.
