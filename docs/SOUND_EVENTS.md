# Звуковые события проекта

Здесь описан текущий звуковой API браузерной реализации. Цель документации механик — Java Edition 1.19.

- Стабильные ключи событий находятся в src/game/sounds.js, экспорт SOUND_EVENTS.
- GameSounds.playEvent(id, material) возвращает false для неизвестного события.
- Web Audio создаётся лениво после пользовательского жеста.
- setEnabled() отключает звук; setVolume() ограничивает громкость диапазоном 0..1.
- Звуки синтезируются осцилляторами. Это оригинальные процедурные сигналы, не записи и не точные копии ванильных звуков.

Категории: блоки (разрушение, установка, шаги, двери, сундуки, печь, ноты); сущности (урон игроку/мобам, подбор/выбрасывание предмета, стрелы, взрыв, торговля); предметы (экипировка, рыбалка); среда (дождь, гром, вода, лава); интерфейс (клик, уведомление).

Ограничения: пока нет пространственного панорамирования, затухания по расстоянию, случайных вариантов, музыкального движка, потокового OGG и полной таблицы звуковых событий Java 1.19. Эти системы нельзя считать реализованными только потому, что есть синтезированные сигналы.
