# Эталон: Minecraft Java Edition 1.12.2

С этого момента целевая версия проекта — **1.12.2** (раньше в PARITY.md был 1.20.x).
Значения и механики берутся из 1.12.2; текстуры, звуки и шрифт остаются оригинальными.

## Исправления в исходном документе

- Зачарованное золотое яблоко в 1.12.2 крафтится: 8 золотых блоков + 1 яблоко.
- Океанские монументы есть в 1.12.2 (появились в 1.8). Пункт «нет подводных монументов» неверен.
- В разделе 19.5 удалить черновой текст «Медленного падения? Нет…» и «Левитации? Это эффект шалкера…».
