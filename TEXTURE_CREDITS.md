# Texture credits

The game loads community-authored texture assets at runtime from these projects:

- **Floydicus Old Pack** by OverFloyd: https://github.com/OverFloyd/floydicus-old-pack
  - Reuse is permitted by the project's `Copyright.txt` when the author or relevant material owners are credited.
  - Used for general block, terrain, item and interface textures where matching assets exist.
- **Simple Resource Pack (SimpleRP)** by elhedran: https://github.com/elhedran/SimpleRP
  - The project's README states that its SVG sources are GPL-licensed and rendered images may be used with a link back to the project.
  - Used for leaf, log, sapling and selected legacy block textures.

The game does not load textures from ItsBrian. Texture files that are unavailable in these sources are left to the existing atlas fallback; no third-party texture is silently attributed to this project.
