# Texture credits

The game loads available block and foliage textures from **Simple Resource Pack (SimpleRP)** by elhedran:

- Repository: https://github.com/elhedran/SimpleRP
- The project's README states that its SVG sources are GPL-licensed and rendered images may be used with a link back to the project.
- Used for leaf, log, sapling, terrain and other matching block textures.

The game no longer loads textures from ItsBrian. SimpleRP does not contain every texture used by this game; unmatched blocks, item icons and interface elements continue to use the game's existing local assets until a complete, appropriately licensed source is available.
